# Crédits

Ce jeu utilise des ressources libres. Merci à leurs auteurs. Ce fichier est généré par `npm run assets` (`scripts/build-lpc.mjs`) : ne pas le modifier à la main, modifier `scripts/credits-template.md`.

## Personnages

Sprites assemblés avec le [Universal LPC Spritesheet Character Generator](https://github.com/LiberatedPixelCup/Universal-LPC-Spritesheet-Character-Generator) (Liberated Pixel Cup, commit `9bf06be193b053db256b2536824af426de046aa2`). Chaque couche utilisée est listée ci-dessous avec ses auteurs et ses licences (source : `CREDITS.csv` du dépôt). Les couches sont recolorisées par palette ; les sprites obtenus sont des œuvres dérivées, à publier avec attribution et dans les mêmes conditions (CC-BY-SA 3.0 / GPL 3.0 / OGA-BY 3.0 selon la couche).

# Prison Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development.

**Goal:** A prison building (400 hp) that jails KO'd Caïds, defended by 5 guard police, releasing every jailed Caïd when destroyed, rebuildable.

**Architecture:** `prison` is a new building target (`Targets`, `DISTRICT.targets`, casse kind `prison` from round 4). A sim module `Prison` holds `jailed: number`, guards (allies from `src/sim/allies.ts`, role `guard`, post radius 160) and the release logic hooked on `BuildingDestroyed('prison')` and on the Caïd KO (`caidDown`). Render/HUD read the snapshot and events.

**Tech Stack:** TypeScript, Phaser 4, Vitest, deterministic sim.

**Spec:** `docs/superpowers/specs/2026-10-22-prison-design.md`. **Prerequisite:** the emergency-services plan (allies, booth targets) is merged on the branch.

## Global Constraints

- Deterministic sim, no `Math.random`; `npm run typecheck`, `npx vitest run`, `npm run bench` (<= 0.3 ms/step), `npm run build` pass. Trailer `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`. Never merge or push without the user's go.
- Prison 400 hp, points +8 / −3 / +5, open from round 4; 5 guards with a Caïd's hp for the current round; guards only defend (160 px post radius), back at the end of the round unless the prison is ruined; Caïd KO jails (+5 as before) only while the prison stands; destroyed = all jailed Caïds released at once at the prison door with the current round's Caïd hp, added to the round roster; rebuilt by toolbox at 60 % hp, released Caïds stay free.

## Review Focus

- Prison destroyed with 0 jailed Caïds: nothing released, no crash (test).
- Caïd KO while the prison is ruined: not jailed (test).
- Several Caïds jailed then release: each counts in roster T and the K<=T invariant holds (test).
- Guard KO'd then prison ruined before round end: does not return (test).
- Determinism with same seed (test).

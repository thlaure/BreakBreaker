# Security policy

BreakBreaker is a static browser game: it has no server, no accounts and collects no personal data (only your best score is kept in your own browser).

If you find a security problem, please report it privately with [GitHub's private vulnerability reporting](https://github.com/thlaure/BreakBreaker/security/advisories/new) rather than in a public issue. You will get an answer as soon as possible.
